---
name: reality-first
description: Evidence protocol for Telegram updates, provider calls and deployment.
---
Inspect actual repository, runtime and webhook configuration. Establish exact HEAD, route mapping, environment contract, provider adapters and baseline. Classify material statements as VERIFIED, CORROBORATED, ESTIMATE, ASSUMPTION, UNKNOWN or DISPUTED. Distinguish unit tests from real Telegram delivery and live model requests. Record sanitized evidence, command, exit code and deployed SHA. Never claim webhook configuration, provider access, bot delivery or deployment without direct evidence.
